# retiretui_mcp

The [RetireTui](https://github.com/kenianbei/retiretui) Model Context Protocol
server, run as `retiretui mcp`: plan files in one directory served to AI agents
over stdio - read, validated, written, projected, searched and run through
markets.

It is internal to RetireTui's own crates and makes no promise of a stable API.
