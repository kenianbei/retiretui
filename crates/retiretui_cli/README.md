# retiretui_cli

The [RetireTui](https://github.com/kenianbei/retiretui) command line, run as
`retiretui`'s commands: plans validated, projected year by year, compared,
searched for conversion ladders and claim ages, run through markets, and given a
statement's earnings.

It is internal to RetireTui's own crates and makes no promise of a stable API.
