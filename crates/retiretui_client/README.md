# retiretui_client

What every [RetireTui](https://github.com/kenianbei/retiretui) interface - the
command line, the agent server, the terminal planner and the browser app -
shares over `retiretui_engine`: the words a plan is said in, the forms it is
edited through, the documents it is kept in, and the store that keeps them.

It is internal to RetireTui's own crates and makes no promise of a stable API.
